# Модельная студия

Desktop-приложение для локальных LLM: запуск моделей, текстовый чат, OpenCode, измерения и подбор настроек. Python + PySide6 / Qt Quick; данные хранятся локально в SQLite.

## Запуск

**Откройте `Запустить.pyw` или `Студия.pyw`.** Лаунчер использует `.venv` рядом с проектом и не зависит от имени рабочей папки.

Готовая Windows-сборка: **`dist/ModelStudio/ModelStudio.exe`**. Для переноса копируйте весь каталог `ModelStudio`, включая `_internal`. Python отдельно ей не нужен. Модели, Ollama, llama-server и OpenCode устанавливаются отдельно.

При первом запуске из исходников импортируются настройки прежнего измерителя рядом с проектом. В готовой сборке прежнюю папку выбирают явно: **Настройки → Импортировать**. Исходные файлы сохраняются.

## Ежедневная работа

1. В **Моделях** добавьте GGUF-файл/папку либо подключите Ollama в настройках. Для GGUF укажите `llama-server.exe`.
2. В **Запуске** выберите модель и контекст; нажмите **Запустить модель**. Изменение параметров в форме не меняет уже работающую сессию.
3. Откройте встроенный **Чат** либо выберите папку проекта системным диалогом и нажмите **Открыть OpenCode**.
4. В **Исследовании** запустите быстрый тест или ограниченный подбор настроек. Результаты сохраняются автоматически; отчёт можно скопировать, экспортировать в TXT/JSON и открыть его папку.
5. **Выгрузить** освобождает модель. Удаление файла модели сохраняет её историю в архиве.

Рекомендации появляются только при наличии сопоставимых проверенных замеров. «Нет данных» означает отсутствие измерения, а не нулевую нагрузку. RAM системы, память GPU и буферы модели показываются отдельно.

## Данные и восстановление

`%LOCALAPPDATA%/ModelStudio`: `studio.db`, `reports`, `logs`, `backups`, `cache`. Переименование проекта не перемещает эти данные. Резервная копия и восстановление доступны в настройках. При восстановлении текущая БД предварительно копируется. Запущенные задачи после аварийного закрытия помечаются прерванными; исследование продолжается только по команде пользователя.

## Разработка

Python 3.11+; проверено на Windows с Python 3.14.7.

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -e .
.venv\Scripts\python.exe -m model_studio
.venv\Scripts\python.exe -m unittest discover -s tests -q
```
