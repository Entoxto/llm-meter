# Bonsai 2: обычная PQ2_0 и Abliterated PQ2_0 MTP

Локальный A/B-тест 24 сентября 2026 года на NVIDIA GeForce RTX 4090 Laptop GPU
(16 GiB). Обе модели запускались **одной и той же** отдельной сборкой
`d8f26eec-bonsai-mtp` на одном адресе последовательно. Общие флаги:
`-c 32768 -np 1 -ngl 99 -fa on --jinja`; у MTP-варианта дополнительно
`--spec-type draft-mtp --spec-draft-n-max 2`. Одинаковые prompt, temperature=0,
seed=42, прогрев до 16 и три запроса по 512 выходных токенов. Каждый замер
обработал 103 входных токена без кеша и выдал 512 выходных. Результаты — медианы
трёх замеров, прогрев не учитывался.

| Показатель | Ternary-Bonsai-2-27B-PQ2_0 | Abliterated PQ2_0 MTP |
| --- | ---: | ---: |
| Генерация, ток/с | 57,39 (54,05–57,43) | 76,36 (71,81–76,48) |
| Обработка prompt, ток/с | 527,36 | 377,75 |
| TTFT, с | 0,295 | 0,419 |
| Буфер весов в VRAM, GiB | 6,39 | 6,81 |
| CPU model buffer, GiB | 0,31 | 0,31 |
| Offload | 65/65 слоёв | 66/66 слоёв |
| GPU занято за весь тест, среднее/пик | 92,4% / 97% | 84,7% / 96% |
| Общая занятая VRAM компьютера, пик | 12,86 GiB | 13,84 GiB |
| Успешных замеров | 3/3 | 3/3 |

Генерация MTP-варианта была быстрее на **33,0%**. Сервер вернул
`draft_n=459/457/482` и `draft_n_accepted=281/281/269` по замерам:
831 принятый из 1398 предложенных токенов (59,4%). Лог запуска также
зафиксировал `draft-mtp` и инициализацию speculative context. Таким образом,
MTP действительно использовался. Более низкая скорость prompt и более высокий
TTFT — результат именно этого короткого prompt на данном компьютере;
длина 103 токена делает замер prefill чувствительным к накладным расходам.

Модели отличаются не только MTP-head, но и abliteration весов; это сравнение
двух пользовательских моделей, а не чистая оценка эффекта одного алгоритма.
Во время теста другой локальный сервер оставался загруженным в GPU. Показатель
пиковой VRAM и загрузка GPU относятся ко всему компьютеру, а не только к
тестируемому процессу. Буферы весов не включают KV и compute; CPU buffer не
равен фактическому рабочему набору RAM процесса.

Отдельная проверка 128K: сервер подтвердил `context_limit=131072`, сгенерировал
512 токенов и вернул `draft_n=538`, `draft_n_accepted=241`. Это проверка
запуска и MTP, **не** полный A/B-бенчмарк на 128K. При почти полной VRAM
(около 16013 MiB, включая другой сервер) скорость составила 15,6 ток/с;
длинный контекст на этой карте существенно увеличивает нагрузку на память.
