# Проверка интерфейса v2

24 сентября 2026. Снимки сделаны в Qt 6.11 / Fusion при размере окна 1488 × 1060. Использован изолированный `--demo` каталог: показанные модель и цифры являются только демонстрационными данными для проверки интерфейса. Реальные запуск, тест и исследование снимками не проверялись.

Дополнительно проверены финальные состояния на изолированных демонстрационных снимках:

- [02 — работающая сессия](qa/02-running.png): память устройства, RAM системы, буферы и источник offload различимы; чат/OpenCode и выгрузка доступны.
- [08 — прогресс исследования](qa/08-research-progress.png): этап, прогресс, завершённые конфигурации и остановка помещаются в сетке. После снимка подпись `completed` переведена через общий словарь статусов.

Все десять состояний просмотрены. Это визуальная проверка; сведения о реальном backend находятся в [IMPLEMENTATION.md](../IMPLEMENTATION.md). Отдельно проверен запуск с настоящей библиотекой из прежних настроек: обнаружены четыре записи, включая вспомогательный mmproj. Переполнение QVariant большими Windows file ID исправлено; повторный захват выполнен без ошибок.

Проверка `pyside6-qmllint` всех QML-файлов завершилась без ошибок. Для основных пяти разделов успешно выполнен offscreen-захват через `python -m model_studio --data-dir .test-data/preview --demo --page N --capture ...`. Подсостояния работающей сессии, прогресса и истории дополнительно захвачены непосредственно из Qt-окна с изолированными демонстрационными данными.
